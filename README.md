# Digital Forensics - Group 17 Website

## Project Overview
This project is a static website built to showcase our research into the field of Digital Forensics. The site highlights the importance of recovering, investigating, and analyzing material found in digital devices, acting as a central hub for our coursework and findings. It features a clean design, responsive layout, scroll animations, and an interactive contact form.
